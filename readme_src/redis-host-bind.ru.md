# Режимы работы сети

[English](redis-host-bind.en.md) | **Русский**

В зависимости от ваших задач, вы можете переключать режим доступности Redis одной переменной `REDIS_HOST_BIND_IP` в файле `.env`:

1. **Локальный режим**
    * **Настройка:** `REDIS_HOST_BIND_IP=127.0.0.1`
    * **Как работает:** Из интернета порт закрыт намертво. Приложения, запущенные в соседних Docker-контейнерах в сети `redis_network`, подключаются без проблем. Вы можете подключиться к базе с хост-машины или через SSH-туннель.

2. **Публичный режим**
    * **Настройка:** `REDIS_HOST_BIND_IP=0.0.0.0`
    * **Как работает:** Порт Redis открывается во внешний интернет. Вы сможете подключаться к нему напрямую из любой точки мира (например, через Redis Insight на рабочем ПК).
    * *Внимание:* Обязательно установите длинный и сложный `REDIS_PASSWORD` перед включением этого режима.
